# 锦囊 SafeKeep

一个**本地零知识密码库**：所有条目在浏览器内加密后才写入本地存储，服务端不存在，
数据不经任何网络上传。忘记主密码且丢失恢复码时，任何人都无法打开（包括开发者本人）。

## 运行

Web Crypto（`crypto.subtle`）只在 HTTPS 或 `localhost` 这类**安全上下文**下可用，
直接双击 `index.html`（`file://`）部分浏览器无法加密。请用本目录的零依赖服务器：

```bash
node serve.cjs            # 默认 http://127.0.0.1:8123/index.html
node serve.cjs 9000       # 指定端口
```

仅监听 `127.0.0.1`，不对外暴露；也可用 `python -m http.server 8123` 替代。

## 功能

- 创建保险库：主密码派生 32 字节 `vaultKey`，再派生恢复码；**抄写确认恢复码前不落盘**。
- 条目管理：登录 / 笔记等类型，字段、网址、备注、标签、收藏、搜索、回收站、恢复、彻底删除。
- 加密：AES-256-GCM；每次写入新随机 IV；连 URL / 标题等元数据一并加密，本地存储全量无明文。
- 解锁：主密码或恢复码；密文被篡改会被 GCM 认证标签拒绝。
- 改主密码：只重新包裹 `vaultKey`，**不重加密任何条目**；旧主密码立即失效。
- 恢复码轮换：生成新码即作废旧码。
- 密码生成器：指定长度、排除易混淆字符、短语模式；熵值如实标注不虚标。
- 安全健康：弱密码 / 复用 / 长期未更新检查。
- 自动锁定：空闲超时（可配 1/5/15/30 分钟或关闭）+ 切到后台立即锁定；锁定清内存明文与 DOM，密文保留。
- 解锁失败退避：第 N 次失败等待 `2^(N-1)` 秒（上限 30 秒）。
- 剪贴板：复制后按设定秒数自动清除，且不误清用户随后自行复制的内容。
- 加密备份：导出纯密文 JSON，可离线保存、跨设备导入；导入前二次确认覆盖。

## 安全模型

| 层 | 说明 |
| --- | --- |
| 密钥派生 | PBKDF2-SHA256，600000 次迭代，随机 salt |
| 密钥包裹 | `vaultKey`（32B）由主密码/恢复码派生的 KEK 经 AES-GCM 包裹后存储 |
| 条目加密 | `vaultKey` + 每条目独立随机 IV，AES-256-GCM，含认证标签 |
| 恢复码 | 20 字节随机（160 bit），Crockford 32 字符，8 组；归一化容忍大小写与分隔符 |
| 本地存储键 | `sk.account` / `sk.items` / `sk.rev` / `sk.prefs`，只存密文、salt、包裹密钥、非敏感偏好 |
| 格式标识 | 账户 `safekeep-local v1`，备份 `safekeep-backup` |

**边界与风险**：不防 XSS / 浏览器扩展 / 已受控设备；无云同步、无多端（当前为纯本地单文件版）；
清理站点数据、无痕模式关闭、换浏览器/设备都会导致本地数据丢失，**导出的加密备份是唯一副本**。

KDF 参数、密码生成、健康检查、备份解析）＋ 本地闭环（创建→恢复码→CRUD→搜索/标签/收藏→
