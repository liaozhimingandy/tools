# 认证与授权规范

> **何时读**：登录、注册、会话、Token、密码、权限模型、单点登录相关改动时。
> **前提与优先级**：[../../core/security-principles.md](../../core/security-principles.md)
> §1、§2、§9、§13 是红线；本文件只做落地细化。
> 接口侧要求见 [api.md](api.md)。

---

## 1. 认证与授权分离

- 认证回答"你是谁"，授权回答"你能对哪个对象做什么"；两者独立实现、独立测试。
- 认证成功**不等于**授权通过；每个敏感操作都要重新判定对象级权限。
- 身份来自服务端验证过的会话/令牌，不信任请求体、请求头中自报的用户 ID 或角色。
- 角色/权限变更、账号停用、密码重置后，已签发的凭据必须有失效路径。

## 2. 密码

- 使用带盐的慢哈希（Argon2id / bcrypt / scrypt），不用 MD5/SHA 家族直接哈希。
- 密码永不明文存储、永不写入日志、永不回显到响应或错误信息。
- 密码策略（长度、复杂度、历史、锁定）由项目既有约定决定，不擅自改动影响现有用户。
- 修改密码、重置密码、敏感操作需重新验证身份。
- 重置 Token 一次性、短时效、使用后立即失效；重置链接不放敏感参数。

## 3. 会话与 Token

- Token 明确设置 issuer、audience、过期时间；服务端校验签名、**算法**、过期与受众。
- 不信任令牌头中声明的算法；服务端固定允许的算法白名单。
- 优先使用安全 Cookie（`HttpOnly` + `Secure` + `SameSite`）或授权头；
  不在 URL、日志、Referer 可达位置传递 Token。
- 刷新令牌与访问令牌分离；刷新令牌可轮换、可撤销，泄漏时能被单独作废。
- 登出/注销必须有服务端失效机制，不只是"前端删掉 Token"。
- 见 [../../core/security-principles.md](../../core/security-principles.md) §9。

## 4. 授权模型

- 默认拒绝（deny by default）：未显式允许的操作一律拒绝。
- 对象级授权针对每个资源 ID 判定；列表、导出、批量、管理端接口逐条过滤。
- 权限判定集中在服务端一处实现，避免每个接口各写一份而遗漏。
- 缓存鉴权结果时，缓存键必须包含身份 + 对象 + 操作 + 权限版本；权限变更后能失效。
- 服务端渲染/前端隐藏都不是权限控制，见
  [../../core/security-principles.md](../../core/security-principles.md) §13。

## 5. 多租户与隔离

- 租户上下文来自可信身份，不来自请求参数；数据访问层强制带租户条件。
- 缓存键、消息队列 topic、文件名、导出任务、搜索索引都包含租户维度。
- 跨租户的运营/管理能力单独授权并留审计日志。

## 6. CSRF、枚举与滥用防护

- 基于 Cookie 的状态变更接口必须有 CSRF Token / `SameSite` + 来源校验，见
  [../../core/security-principles.md](../../core/security-principles.md) §5。
- 登录、注册、密码重置、验证码接口必须限流，并有账号锁定或退避策略。
- 认证失败信息保持统一，不区分"用户不存在"与"密码错误"，避免账号枚举。
- 时序差异不足以作为唯一防护，但错误分支不应显著暴露账号存在性。
- 关键认证事件写审计日志（谁、何时、来源、结果），不含凭据本身。

## 7. 密钥与凭据管理

- 签名密钥、客户端密钥、数据库连接串不进代码与版本库；通过密钥管理/环境注入获取。
- 密钥有轮换方案：轮换期间能验证新旧密钥，轮换后旧密钥失效。
- 生产与测试/开发凭据隔离，不允许共用。
- 见 [../../core/security-principles.md](../../core/security-principles.md) §8。

## 8. 测试清单

每个认证/授权改动至少验证：

1. 未认证、无效/过期/错误受众的 Token 被拒绝；
2. 有效身份访问**他人**资源被拒绝（IDOR）；
3. 角色变更后旧凭据/缓存权限失效；
4. 登出或撤销后 Token 不可再用；
5. 多租户场景：租户 A 无法读写租户 B 的数据；
6. 认证失败信息不泄漏账号存在性；限流生效；
7. 日志与错误信息中不含密码、Token、完整请求体。

见 [../../core/testing-principles.md](../../core/testing-principles.md) §4、§7。
