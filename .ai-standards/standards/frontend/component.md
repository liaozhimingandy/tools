# 组件设计规范

> **何时读**：设计或重构可复用组件、决定状态归属、划分容器与展示组件时。
> **前提**：[../../core/engineering-principles.md](../../core/engineering-principles.md)
> §1、§2、§6（单一职责、内聚耦合、避免过度设计）；
> [../../core/architecture-principles.md](../../core/architecture-principles.md) §3、§4。
> 框架专属写法见 [vue.md](vue.md)。

---

## 1. 组件的唯一职责

- 一个组件只解决一个交互/展示问题；判断标准：能否用一句话说清它的职责。
- 若组件同时负责"取数 + 业务规则 + 渲染 + 权限判断"，拆成容器与展示组件，
  或把规则移到 service / composable。
- 组件不直接访问全局状态以外的外部系统；数据通过明确输入传入。
- 不为"以后可能复用"预设大量配置项；有第二个真实使用场景时再抽象。

## 2. 接口（props / emits / slots）

- 输入接口最小化：只暴露当前确实需要的属性；每个 prop 有明确类型、默认值与语义。
- 命名表达业务含义，不暴露实现细节（用 `items` 而非 `internalArray`）。
- 单向数据流：组件不修改传入数据，变更通过事件上抛；不由子组件直接写父级状态。
- 事件名稳定、可预期，携带最小必要载荷；不在事件里传整个内部状态对象。
- 插槽用于**内容**定制，不用于传递行为逻辑；作用域插槽暴露的数据要写清形状。

## 3. 状态归属

**规则**：状态放在"需要它的最低公共祖先"，且只有唯一写入方。

| 状态类型 | 归属 |
| --- | --- |
| 临时 UI（展开/收起、输入草稿） | 组件内部 |
| 跨若干兄弟组件共享 | 最近公共父级 |
| 跨路由/跨页面共享、且需缓存 | 项目既有全局状态方案 |
| 服务端数据 | 数据层 + 缓存，不作为组件私有状态长期持有 |
| URL 可表达的状态（页码、筛选、选中项） | 路由/查询参数 |

- 派生值由输入计算得到，不额外存一份可变副本（避免两份状态不同步）。
- 不把同一份数据同时存在组件内部、全局 store 和 URL 三处。
- 表单状态明确：受控/非受控、校验时机、提交失败后的状态保留策略。

## 4. 组合优于继承与嵌套

- 用组合（`children` / `slot` / 子组件拼接）表达变化，不用深层继承。
- 嵌套层级过深（超过约 4 层）时检查是否是职责划分问题，而不是继续加透传层。
- 避免 prop drilling：多层透传同一参数时，把状态上移或用组合替代。
- 不引入只有一个消费者的"高阶组件"或包装层。

## 5. 渲染与边界状态

- 每个数据驱动组件必须明确四种状态：加载中、空数据、成功、失败；
  不为省事只实现成功态。
- 失败态提供可理解的信息与重试入口，不泄漏技术细节。
- 列表渲染使用稳定唯一 key；大列表考虑分页或虚拟滚动。
- 交互给出即时反馈（禁用、loading、禁用重复提交），并在异步完成后恢复。
- 不阻塞主线程做大量计算；必要时分帧或移到后台处理。

## 6. 样式与可访问性边界

- 组件的样式作用域明确（scoped / CSS Modules / 项目既有方案），不污染全局。
- 组件不假设特定页面布局；尺寸由使用方控制，内部只负责自身排版。
- 可访问性细则见 [ui.md](ui.md)；组件至少保证可键盘操作、焦点可见、
  表单控件有关联标签、状态变化可被辅助技术感知。

## 7. 可测试性与文档

- 组件能在不启动完整应用的情况下被渲染测试；外部依赖通过输入注入。
- 为每个可复用组件写明：用途、输入、事件、边界状态、不适用示例、
  一个最小可运行用例。
- 测试断言渲染结果与交互行为，不断言内部方法调用顺序，见
  [../../core/testing-principles.md](../../core/testing-principles.md) §10。
- 公开组件的接口变更按契约变更处理，见
  [../../core/engineering-principles.md](../../core/engineering-principles.md) §13。

## 8. 反模式清单

- 一个组件上千行、承担多个业务域；
- 通过全局事件总线传递本该用 props 表达的数据；
- 复制粘贴一个组件再改几行，而不是提取真实共享部分；
- 把权限判断写在组件里当作安全控制；
- 为单个页面创建"通用组件库"；
- 只实现成功渲染路径，忽略空态与失败态。
