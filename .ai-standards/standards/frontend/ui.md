# UI 与可访问性规范

> **何时读**：样式、布局、响应式、交互反馈、可访问性、主题与图标相关改动时。
> **前提**：[component.md](component.md)、
> [../../core/security-principles.md](../../core/security-principles.md) §4（XSS）。
> **原则**：遵循项目既有设计系统；不擅自引入新的 UI 框架或样式方案，见
> [../../core/ai-behavior.md](../../core/ai-behavior.md) §3.2。

---

## 1. 设计系统优先

- 颜色、间距、字号、圆角、阴影、动效时长使用项目既有 token / 变量，不写魔法值。
- 复用既有组件与模式；不因为"顺手"再造一个按钮/表单/弹窗。
- 新增 token 必须有第二个使用场景并说明原因，否则直接用既有值。
- 图标、字体等静态资源走项目既有资源管理方式，不在组件里内联大段 base64。

## 2. 布局与响应式

- 使用弹性布局/网格，不用固定像素宽高拼出"刚好能看"的页面。
- 断点遵循项目既有定义；不新增只针对某一台设备的特殊分支。
- 内容优先：在窄屏下保证信息可达、操作可完成，而不是简单缩放。
- 处理长文本、超长名称、空数据、极端数量（0 / 1 / 很多）时的布局不塌陷。
- 不依赖 `position: fixed` 掩盖滚动容器问题；滚动边界与层级要明确。

## 3. 交互反馈

- 每个用户操作都有可感知的反馈：即时状态、进行中状态、成功/失败结果。
- 异步操作期间禁用重复提交并给出进度；失败保留用户输入，提供明确重试入口。
- 破坏性操作需要二次确认，并说明后果；不用一个 `confirm()` 草草带过关键流程。
- 加载态使用骨架/占位而非整屏白屏；超时与失败有明确文案。
- 动效克制：尊重系统"减少动效"偏好，不把关键操作藏在动画之后。

## 4. 可访问性（最低要求）

- 所有可交互元素可键盘到达，焦点顺序符合视觉顺序，焦点样式清晰可见。
- 语义优先：用正确的原生元素（`button` / `a` / `label` / `table` 等），
  不为样式把 `div` 伪装成按钮。
- 表单控件有关联标签、错误提示与描述；错误用文本表达，不仅用颜色。
- 图片与图标有等价文本；纯装饰元素对辅助技术隐藏。
- 颜色对比度满足 WCAG AA；不只用颜色区分状态（红/绿需配文字或图标）。
- 状态变化（弹窗、错误、异步完成）能被辅助技术感知（合适的 `aria-live` / 焦点管理）。
- 页面有合理的标题层级；不使用多级跳级的标题结构。

## 5. 内容与文案

- 错误文案说明"发生了什么 + 用户能做什么"，不显示堆栈、SQL 或内部标识。
- 不把技术字段名直接展示给用户；日期、数字按项目既有本地化规则格式化。
- 空状态给出下一步动作，而不是只显示"暂无数据"。
- 文案中的占位值明确标注，不把示例数据当成真实内容发布。

## 6. 安全

- 不使用 `innerHTML` / `v-html` / `dangerouslySetInnerHTML` 渲染不可信内容；
  富文本须经服务端白名单净化，见
  [../../core/security-principles.md](../../core/security-principles.md) §4。
- 绑定到 `href`/`src` 的外部 URL 校验协议白名单，拒绝 `javascript:` / `data:`。
- 不把 Token、个人信息、完整请求体写入前端日志、埋点或 `localStorage` 而不加说明。
- 前端隐藏、禁用按钮都不是权限控制；服务端必须独立做对象级授权，见
  [../../core/security-principles.md](../../core/security-principles.md) §13。
- 第三方脚本/字体/CDN 引入需评估来源与 CSP 影响；不擅自新增外部资源。

## 7. 主题与一致性

- 明暗主题（若项目支持）都使用语义化 token，不硬编码颜色。
- 高对比度、缩放至 200%、减少动效等系统偏好下不丢失功能。
- RTL（若项目支持）下不依赖左右方向的固定间距写法。

## 8. 验证清单

提交前实际确认：

1. 键盘可完成核心流程，焦点可见；
2. 窄屏、长文本、空态、失败态布局正常；
3. 对比度达标，状态不只靠颜色；
4. 加载/失败/成功三类反馈齐全；
5. 无不可信 HTML 注入、无未校验的外部 URL；
6. 使用既有 token 与组件，未引入新框架或魔法值；
7. lint、类型检查、测试、构建已实际运行并记录结果。
